# Insta Clone

This repository contains a full-stack Instagram-like web app scaffold (MERN):

- Backend: Express + MongoDB (Mongoose), JWT auth, file uploads with multer, socket.io notifications.
- Frontend: React (Vite) + Tailwind CSS, pages for Register/Login, Feed, Create Post, Profile.
- docker-compose.yml to run MongoDB locally.

Instructions
1. Copy .env.example to backend/.env and set MONGO_URI, JWT_SECRET, PORT.
2. Start MongoDB: `docker-compose up -d`.
3. Backend: `cd backend && npm install && npm run dev`.
4. Frontend: `cd frontend && npm install && npm run dev`.
